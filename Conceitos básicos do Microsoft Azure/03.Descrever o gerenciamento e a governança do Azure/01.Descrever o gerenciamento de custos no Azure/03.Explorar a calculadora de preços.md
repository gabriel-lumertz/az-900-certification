# Explorar a calculadora de preços

A calculadora de preços é uma calculadora que ajuda você a  entender possíveis despesas do Azure. A calculadora de preços é  acessível pela Internet e permite que você crie uma configuração. A  calculadora TCO (Custo Total de Propriedade) foi desativada.

## Calculadora de preços

A calculadora de preços foi projetada para fornecer um custo estimado para provisionamento de recursos no Azure. Você pode obter uma  estimativa para recursos individuais, criar uma solução ou usar um  cenário de exemplo para ver uma estimativa dos gastos do Azure. O foco  da calculadora de preços é o custo dos recursos provisionados no Azure.

> [!NOTE]
>
> A calculadora de preços é apenas para fins de informações. Os preços  são apenas uma estimativa. Nada é provisionado quando você adiciona  recursos à calculadora de preços e não será cobrado por nenhum serviço  selecionado.
>
> Com a calculadora de preços, você pode estimar o custo de todos os  recursos provisionados, incluindo computação, armazenamento e custos de  rede associados. Você pode até mesmo considerar diferentes opções de  armazenamento, como tipo de armazenamento, camada de acesso e  redundância.
