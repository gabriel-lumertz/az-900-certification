# Exercício – Estimar os custos da carga de trabalho usando a calculadora de preços

Neste exercício, você usará a calculadora de preços para estimar o custo da execução de um aplicativo Web básico no Azure.

Comece definindo quais serviços do Azure você precisa.

 Observação

A calculadora de preços é apenas para fins de informações. Os preços  são apenas uma estimativa e você não será cobrado por nenhum serviço  selecionado.

## Definir seus requisitos

Antes de executar a calculadora de preços, você precisa ter uma noção de quais serviços do Azure você precisa.

Para um aplicativo Web básico hospedado em seu datacenter, você pode executar uma configuração semelhante à seguinte.

Um aplicativo Web ASP.NET que é executado no Windows. O aplicativo  Web fornece informações sobre o inventário e os preços do produto. Há  duas máquinas virtuais conectadas por meio de um balanceador de carga  central. O aplicativo Web se conecta a um banco de dados do SQL Server  que contém informações de inventário e preços.

Para migrar para o Azure, você pode:

- Use instâncias de Máquinas Virtuais do Azure, semelhantes às máquinas virtuais usadas em seu datacenter.
- Use o Gateway de Aplicativo do Azure para balanceamento de carga.
- Use o Banco de Dados SQL do Azure para armazenar informações de inventário e preços.

Aqui está um diagrama que mostra a configuração básica:

![um diagrama mostrando uma possível solução do Azure para hospedar um aplicativo.](https://learn.microsoft.com/pt-br/training/wwl-azure/describe-cost-management-azure/media/estimate-costs-architecture-171ae4c1.png)

Na prática, você definiria seus requisitos com mais detalhes. Mas aqui estão alguns fatos e requisitos básicos para começar:

- O aplicativo é usado internamente. Não é acessível aos clientes.
- Esse aplicativo não requer uma grande quantidade de poder de computação.
- As máquinas virtuais e o banco de dados são executados o tempo todo (730 horas por mês).
- A rede processa cerca de 1 TB de dados por mês.
- O banco de dados não precisa ser configurado para cargas de trabalho de alto desempenho e não requer mais de 32 GB de armazenamento.

## Explorar a calculadora de preços

Vamos começar com um tour rápido pela calculadora de preços.

1. Acesse a [Calculadora de preços](https://azure.microsoft.com/pricing/calculator/).

2. Observe as seguintes guias:

   ![Uma captura de tela da barra de menus da calculadora de preços com a guia Produtos selecionada.](https://learn.microsoft.com/pt-br/training/wwl-azure/describe-cost-management-azure/media/price-calculator-menu-bar-4a43e988.png)

   - **Produtos** É aqui que você escolhe os serviços do  Azure que deseja incluir em sua estimativa. Você provavelmente passará a maior parte do tempo aqui.
   - **Cenários de exemplo** Aqui, você encontrará várias arquiteturas de referência ou soluções comuns baseadas em nuvem que podem ser usadas como ponto de partida.
   - **Estimativas salvas** Aqui você encontrará suas estimativas salvas anteriormente.
   - **perguntas frequentes** Aqui, você descobrirá respostas para perguntas frequentes sobre a calculadora de preços.

## Estimar sua solução

Aqui você adiciona cada serviço do Azure necessário à calculadora. Em seguida, você configura cada serviço para atender às suas necessidades.

> [!TIP]
>
> Verifique se você tem uma calculadora limpa sem nada listado na  estimativa. Você pode redefinir a estimativa selecionando o ícone de  lixeira ao lado de cada item.

### Adicionar serviços à estimativa

1. Na guia **Produtos**, selecione o serviço de cada uma dessas categorias:

| **Categoria**   | **Serviço**                     |
| --------------- | ------------------------------- |
| Computação      | **Máquinas Virtuais**           |
| Bancos de Dados | **Banco de Dados SQL do Azure** |
| Rede            | **Gateway de Aplicativo**       |

2. Role até o final da página. Cada serviço é listado com sua configuração padrão.

### Configurar serviços para atender aos seus requisitos

1. Em **Máquinas Virtuais**, defina estes valores:

| **Configuração**    | **Valor**                         |
| ------------------- | --------------------------------- |
| Região              | **Oeste dos EUA**                 |
| Sistema Operacional | **Windows**                       |
| Tipo                | **(somente sistema operacional)** |
| Camada              | **Standard**                      |
| Instância           | **D2 v3**                         |
| Máquinas virtuais   | **2** x **730 horas**             |

Deixe as configurações restantes em seus valores atuais.



2. Em **Banco de Dados SQL do Azure**, defina estes valores:

| **Configuração**                  | **Valor**                |
| --------------------------------- | ------------------------ |
| Região                            | **Oeste dos EUA**        |
| Tipo                              | **banco de dados único** |
| Camada de armazenamento de backup | **RA-GRS**               |
| Modelo de compra                  | **vCore**                |
| Camada de serviço                 | **Uso Geral**            |
| Nível de computação               | **Provisionado**         |
| Geração                           | **Gen 5**                |
| Instância                         | **8 vCore**              |

Deixe as configurações restantes em seus valores atuais.



3. Em **Gateway de Aplicativo**, defina estes valores:

| **Configuração**               | **Valor**                      |
| ------------------------------ | ------------------------------ |
| Região                         | **Oeste dos EUA**              |
| Camada                         | **Firewall de Aplicativo Web** |
| Tamanho                        | **Médio**                      |
| Horários do gateway            | **2** x **730 horas**          |
| Dados processados              | **1 TB**                       |
| Transferência de dados externa | **5 GB**                       |

Deixe as configurações restantes em seus valores atuais.

## Examinar, compartilhar e salvar sua estimativa

Na parte inferior da página, você verá o custo total estimado da  execução da solução. Você pode alterar o tipo de moeda se desejar.

Neste ponto, você tem algumas opções:

- Selecione **Exportar** para salvar sua estimativa como um documento do Excel.
- Selecionar **Salvar** ou **Salvar como** para salvar a estimativa na guia **Estimativas Salvas** para depois.
- Selecione **Compartilhar** para gerar uma URL para que você possa compartilhar a estimativa com sua equipe.

Agora você tem uma estimativa de custo que pode compartilhar com sua  equipe. Você pode fazer ajustes conforme descobre as alterações em seus  requisitos.

Experimente algumas das opções com as quais você trabalhou aqui ou  crie um plano de compra para uma carga de trabalho que você deseja  executar no Azure.
