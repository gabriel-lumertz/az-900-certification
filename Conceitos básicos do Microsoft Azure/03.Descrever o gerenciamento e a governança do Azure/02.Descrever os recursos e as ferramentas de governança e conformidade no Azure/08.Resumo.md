# Resumo

Neste módulo, você aprendeu sobre alguns dos recursos e  ferramentas que pode usar para ajudar na governança do seu ambiente do  Azure. Você também aprendeu sobre as ferramentas que pode usar para  ajudar a manter os recursos em conformidade com os requisitos  corporativos ou regulatórios.

## Objetivos de aprendizagem

Agora você deve ser capaz de:

- Descreva a finalidade do Microsoft Purview.
- Descreva a finalidade do Azure Policy.
- Descreva a finalidade dos bloqueios de recursos.
- Descreva a finalidade do portal de Confiança do Serviço.
