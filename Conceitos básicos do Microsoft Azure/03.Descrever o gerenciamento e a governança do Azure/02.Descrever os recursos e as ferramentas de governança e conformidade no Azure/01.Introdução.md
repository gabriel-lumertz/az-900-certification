# Introdução

Neste módulo, você será apresentado a alguns dos recursos e  ferramentas que você pode usar para ajudar na governança do seu ambiente do Azure. Você também aprenderá sobre as ferramentas que pode usar para ajudar a manter os recursos em conformidade com os requisitos  corporativos ou regulatórios.

## Objetivos de aprendizagem

Depois de concluir este módulo, você poderá:

- Descreva a finalidade do Microsoft Purview.
- Descreva a finalidade do Azure Policy.
- Descreva a finalidade dos bloqueios de recursos.
- Descreva a finalidade do portal de Confiança do Serviço.
