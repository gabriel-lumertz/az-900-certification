# Introdução

Este módulo apresenta recursos e ferramentas para gerenciar e  implantar recursos do Azure. Você aprenderá sobre o portal do Azure (uma interface gráfica para gerenciar recursos do Azure), a linha de comando e as ferramentas de script que ajudam a implantar ou configurar  recursos. Você também aprende sobre os serviços do Azure que ajudam você a gerenciar seus ambientes locais e multinuvem de dentro do Azure.

## Objetivos de aprendizagem

Depois de concluir este módulo, você poderá:

- Descreva o portal do Azure.
- Descreva o Azure Cloud Shell, incluindo a CLI do Azure e o Azure PowerShell.
- Descreva a finalidade do Azure Arc.
- Descreva o ARM (Azure Resource Manager), os modelos do ARM e o Bicep.
