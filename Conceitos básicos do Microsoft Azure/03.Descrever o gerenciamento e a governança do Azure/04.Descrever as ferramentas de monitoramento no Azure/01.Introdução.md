# Introdução

Neste módulo, você será apresentado às ferramentas que ajudam a  monitorar seu ambiente e aplicativos, tanto no Azure quanto em ambientes locais ou multinuvem.

## Objetivos de aprendizagem

Depois de concluir este módulo, você poderá:

- Descrever a finalidade do Assistente do Azure.
- Descrever a Integridade do Serviço do Azure.
- Descrever o Azure Monitor, incluindo o Azure Log Analytics, os alertas do Azure Monitor e o Application Insights.
