# Resumo

Neste módulo, você foi apresentado às ferramentas que ajudam a  monitorar seu ambiente e aplicativos, tanto no Azure quanto em ambientes locais ou multinuvem.

## Objetivos de aprendizagem

Agora você deve ser capaz de:

- Descrever a finalidade do Assistente do Azure.
- Descrever a Integridade do Serviço do Azure.
- Descrever o Azure Monitor, incluindo o Azure Log Analytics, os alertas do Azure Monitor e o Application Insights.

## Recursos adicionais

Os recursos adicionais a seguir destinam-se a fornecer mais  informações sobre tópicos neste módulo ou sobre tópicos adicionais  relacionados a este módulo.

-  [Introdução ao Assistente do Azure](https://learn.microsoft.com/pt-br/learn/modules/get-started-azure-advisor/) é um módulo do Microsoft Learn que ajuda você a começar a usar o Assistente do Azure.
-  [A introdução à Integridade do Serviço do Azure](https://learn.microsoft.com/pt-br/learn/modules/intro-to-azure-service-health/) é um módulo do Microsoft Learn que fornece informações adicionais sobre a Integridade do Serviço do Azure.
- [Monitorar o uso, o desempenho e a disponibilidade de recursos com o Azure Monitor](https://learn.microsoft.com/pt-br/learn/paths/monitor-usage-performance-availability-resources-azure-monitor/) é um roteiro de aprendizagem do Microsoft Learn que se aprofunda no  Azure Monitor. Ele fornece diretrizes úteis sobre como configurar e  obter o máximo do serviço do Azure Monitor.
