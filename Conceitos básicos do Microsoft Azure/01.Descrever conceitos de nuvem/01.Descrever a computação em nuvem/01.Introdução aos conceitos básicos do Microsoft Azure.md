# Introdução aos conceitos básicos do Microsoft Azure

O Microsoft Azure é uma plataforma de computação em nuvem com um conjunto de serviços em constante expansão para ajudá-lo a criar soluções para atender às suas metas de negócios. Os serviços do Azure dão suporte a tudo, de simples a complexo. O Azure tem serviços Web simples para hospedar sua presença de negócios na nuvem. O Azure também dá suporte à execução de computadores totalmente virtualizados que gerenciam suas soluções de software personalizadas. O Azure fornece uma grande variedade de serviços baseados em nuvem, como armazenamento remoto, hospedagem de banco de dados e gerenciamento centralizado de contas. O Azure também oferece novos recursos, como ia (inteligência artificial) e serviços focados em Internet das Coisas (IoT).

Nesta série, você abordará os conceitos básicos de computação em nuvem, será introduzido em alguns dos principais serviços fornecidos pelo Microsoft Azure e aprenderá mais sobre os serviços de governança e conformidade que você pode usar.

## O que são os conceitos básicos do Azure?

Os Conceitos Básicos do Azure são uma série de três roteiros de aprendizagem que o familiarizam com o Azure e seus muitos serviços e recursos.

Se você estiver interessado em serviços de computação, rede ou armazenamento; aprendendo sobre as práticas recomendadas de segurança na nuvem; ou explorando opções de governança e gerenciamento, considere os conceitos básicos do Azure como seu guia coletado para o Azure.

Os conceitos básicos do Azure incluem exercícios interativos que proporcionam experiência prática com o Azure. Muitos exercícios fornecem um ambiente temporário do portal do Azure chamado sandbox, que permite praticar a criação de recursos em nuvem gratuitamente no seu próprio ritmo.

A experiência técnica de TI não é necessária; no entanto, ter conhecimento geral de TI ajudará você a aproveitar ao máximo sua experiência de aprendizagem.

## Por que devo usar os conceitos básicos do Azure?

Se você estiver apenas começando a trabalhar com a nuvem ou se já tiver experiência em nuvem, os conceitos básicos do Azure fornecerão tudo o que você precisa para começar.

Não importa seus objetivos, os conceitos básicos do Azure têm algo para você. Você deverá fazer este curso se:

- Ter interesse geral no Azure ou na computação em nuvem
- Deseja obter a certificação oficial da Microsoft (AZ-900)

A série de roteiros de aprendizagem dos Conceitos Básicos do Azure pode ajudá-lo a se preparar para o Exame AZ-900: Conceitos Básicos do Microsoft Azure. Este exame inclui três áreas de domínio de conhecimento:

| **Área de domínio do AZ-900**                     | **Peso** |
| :------------------------------------------------ | :------- |
| Descrever conceitos de nuvem                      | 25-30%   |
| Descrever a arquitetura e os serviços do Azure    | 35 a 40% |
| Descrever o gerenciamento e a governança do Azure | 30 a 35% |

Cada área de domínio é mapeada para um roteiro de aprendizagem nos Conceitos Básicos do Azure. Os percentuais mostrados indicam o peso relativo de cada área no exame. Quanto maior o percentual, mais perguntas essa parte do exame conterá. Leia a página do exame para obter detalhes sobre quais habilidades são abordadas em cada área.

Esse treinamento ajuda você a desenvolver uma ampla compreensão do Azure.
