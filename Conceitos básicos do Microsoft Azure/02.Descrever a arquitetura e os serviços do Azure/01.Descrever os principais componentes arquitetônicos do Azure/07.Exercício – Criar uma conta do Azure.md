# Exercício – Criar uma conta do Azure

Neste exercício, você usará o portal do Azure para criar um recurso. O foco do exercício é observar como os grupos de recursos do Azure são preenchidos com recursos criados.

 Importante

Você tem a oportunidade de criar um grupo de recursos ao criar a máquina virtual. Se você nomear o grupo de recursos da mesma forma que o nome recomendado, isso facilitará a limpeza no final do exercício.

## Tarefa 1: criar uma máquina virtual

Nesta tarefa, você vai criar uma máquina virtual usando o portal do Azure.

1. Entre no [portal do Azure](https://portal.azure.com/).

2. Selecione Criar um recurso > Computação > Máquina Virtual > Criar.

3. O painel Criar uma máquina virtual é aberto na guia noções básicas.

4. Verifique ou insira os valores a seguir para cada configuração. Se uma configuração não for especificada, deixe o valor padrão.

   **Guia Noções básicas**

   

   | **Configuração**                       | **Valor**                                                    |
   | :------------------------------------- | :----------------------------------------------------------- |
   | Subscrição                             | Selecione a assinatura que você deseja usar para o exercício. |
   | Grupo de recursos                      | Selecione Criar novo e insira `IntroAzureRG` e selecione OK  |
   | Nome da máquina virtual                | `my-VM`                                                      |
   | Região                                 | Manter o padrão                                              |
   | Opções de disponibilidade              | Manter o padrão                                              |
   | Opções de zona                         | Zona auto-selecionada                                        |
   | Zona de disponibilidade                | Manter o padrão                                              |
   | Tipo de segurança                      | Manter o padrão                                              |
   | Imagem                                 | Manter o padrão                                              |
   | Arquitetura de VM                      | Manter o padrão                                              |
   | Executar com desconto do Spot do Azure | Desmarcado                                                   |
   | Tamanho                                | Manter o padrão                                              |
   | Tipo de autenticação                   | Senha                                                        |
   | Nome de usuário                        | `azureuser`                                                  |
   | Senha                                  | Inserir uma senha personalizada                              |
   | Confirmar senha                        | Insira a senha personalizada novamente                       |
   | Portas de entrada públicas             | Nenhum                                                       |

5. Selecione Examinar e criar.

 Importante

Os detalhes do produto incluirão um custo associado à criação da máquina virtual. Essa é uma função do sistema. Se você estiver criando a VM na área restrita do Learn, não incorrerá em nenhum custo.

1. Escolha Criar

Aguarde enquanto a VM é configurada. A implantação está em andamento e mudará Implantação concluída quando a VM estiver pronta.

## Tarefa 2: verificar os recursos criados

Depois que a implantação for criada, você poderá verificar se o Azure criou não apenas uma VM, mas todos os recursos associados de que a VM precisa.

1. Selecione Página inicial.
2. Nos serviços do Azure, selecione Grupos de recursos.
3. Selecione o grupo de recursos **IntroAzureRG**.

Você deve ver uma lista de recursos no grupo de recursos. Os recursos foram criados quando você criou a máquina virtual. Por padrão, o Azure deu a todos eles um nome semelhante para ajudar na associação e os agrupou no mesmo grupo de recursos.

Parabéns! Você criou um recurso no Azure e teve a oportunidade de ver como os recursos são agrupados na criação.

## Limpeza

Para limpar os ativos criados neste exercício e evitar custos desnecessários, exclua o grupo de recursos (e todos os recursos associados).

1. Na home page do Azure, em Serviços do Azure, selecione **Grupos de recursos**.
2. Selecione o grupo de recursos **IntroAzureRG**.
3. Selecione **Excluir grupo de recursos**.
4. Insira `IntroAzureRG` para confirmar a exclusão do grupo de recursos e selecione excluir.
